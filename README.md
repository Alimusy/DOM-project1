# Shopping Cart (DOM project)

A simple shopping cart built with HTML, Bootstrap and vanilla JavaScript DOM events.

## Features

- Adjust each item's quantity with the plus and minus buttons (it never goes below 0)
- Remove an item from the cart with the trash button
- Like an item with the heart button, which turns red and back to black when clicked again
- Total price updates automatically after every change

## Run it

Open `index.html` in a browser, or use a local server such as VS Code Live Server.

Product images go in `assets/` as `baskets.png`, `socks.png` and `bag.png`.
